# 🎵 SurSangeet — KNN Audio Vector Sound Deck

SurSangeet is a full-stack, AI/ML-powered music recommendation platform and player interface. It uses **K-Nearest Neighbors (KNN)** with **Cosine Similarity** vector matching on normalized audio features (danceability, energy, acousticness, valence, tempo, and speechiness) to generate custom playlists based on interactive user mood & activity preference vectors.

---

## ✨ Features

- **Interactive Vector Calibration Wizard**: 5-step questionnaire mapping user mood, energy, danceability, tempo, and acoustic preferences into high-dimensional audio vectors.
- **K-Nearest Neighbors (KNN) Vector Engine**: Fast cosine-distance audio matching across 10,000+ real tracks.
- **Artist Diversity Filtering**: Prevents consecutive artist repeats for dynamic, balanced playlist flows.
- **Retro-Brutalist Hi-Fi Player UI**: Dark-mode aesthetic with an animated spinning vinyl record deck, dynamic hardware tonearm swing, audio progress scrubber, volume controls, and track queue management.
- **Seamless YouTube Audio Integration**: Direct stream playback via YouTube IFrame API with image fallbacks and zero hydration issues.
- **Neon Cloud Database**: PostgreSQL vector persistence hosted on Neon for fast response times.

## ⚡ Quick Start

### 1. Environment Setup

Create `.env` in the `backend/` directory:

```env
DATABASE_URL=postgresql://neondb_owner:YOUR_NEON_PASSWORD@ep-calm-wildflower-aycpps3m-pooler.c-5.us-east-2.aws.neon.tech/neondb?sslmode=require
CORS_ORIGINS=http://localhost:3000,http://localhost:3001
```

---

### 2. Backend Setup & Ingestion

```bash
cd backend

# Create virtual environment
python -m venv venv
venv\Scripts\activate       # On Windows (PowerShell)
# source venv/bin/activate  # On Linux/macOS

# Install dependencies
pip install -r requirements.txt

# Ingest CSV dataset into Neon PostgreSQL
python seed_data.py

# Run FastAPI server
uvicorn app.main:app --reload --port 8000
```

The backend server will run at `http://localhost:8000`.  
API Documentation (Swagger UI) is available at `http://localhost:8000/docs`.

---

### 3. Frontend Setup

```bash
cd frontend

# Install dependencies
npm install

# Run Next.js dev server
npm run dev
```

Open `http://localhost:3000` in your web browser.

## 🧮 How the ML Recommendation Engine Works

1. **Feature Vector Normalization**:
   Audio characteristics are normalized into a 6-dimensional feature vector:
   $$\vec{v} = [\text{danceability}, \text{energy}, \text{valence}, \text{acousticness}, \text{speechiness}, \text{tempo\_norm}]$$

2. **Vector Space Search**:
   The engine computes **Cosine Distance** between the target vector generated by user questionnaire inputs and song vectors in the Neon database:
   $$\text{Cosine Similarity} = \frac{\vec{A} \cdot \vec{B}}{\|\vec{A}\| \|\vec{B}\|}$$

3. **Artist Diversity Enforcement**:
   To prevent single-artist clustering, candidate tracks undergo a deduplication pass ensuring varied artist representation throughout the playlist.

## 📡 API Endpoints

### `POST /api/recommend`
Generates a recommended playlist based on target audio feature preferences.

**Request Body**:
```json
{
  "mood": "Energetic",
  "activity": "Workout",
  "danceability": 0.8,
  "energy": 0.9,
  "acousticness": 0.1,
  "valence": 0.7,
  "limit": 15
}
```

**Response**:
```json
{
  "playlist": [
    {
      "id": 1042,
      "title": "Song Title",
      "artist": "Artist Name",
      "youtube_id": "dQw4w9WgXcQ",
      "thumbnail_url": "https://i.ytimg.com/vi/dQw4w9WgXcQ/hqdefault.jpg",
      "duration": 210,
      "genre": "Pop"
    }
  ]
}
```
